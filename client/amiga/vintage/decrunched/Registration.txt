How to Register
~~~~~~~~~~~~~~~
This terminal software is designed to allow you to access Compunet. Details
of how to use the program are in the ReadMe file on this directory. 

You can use the software to log in to our demonstration area using the the
ID: NEW-USER and the password INTRO. Please don't forget to put the hyphen
in NEW-USER!

The London phone number to access the Compunet system is currently

                        (01)-997 5422

If you want details of a number closer to where you live, then ring us on
(01)-997 2591 (voice) during office hours. The demonstration area is only
available in non-prime times - between 6pm and 8am on weekdays, and all day
at weekends.

pounds and join Compunet (£15.00 quarterly subscription), which will give

The easiest way to do this is to ring us (voice) on (01)-997 2591 and pay
by credit card.  When you ring we will give you all the details that you
need, or send you any extra information.  Alternatively, you can write to us

Perivale, Middlesex UB6 7JB.
