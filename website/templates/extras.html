3D-PRINTED LOGO

A desk plaque of the Compunet logo, for multi-colour printers.

There is no logo file

The Compunet logo doesn't exist in this project as artwork. It exists as a PETSCII frame — the header the server sends at the top of the root directory, the same bytes a C64 receives and draws.

So the model isn't traced from a picture. A script renders that frame through the character ROM and the 16-colour palette from the client specification, then extrudes the pixels into geometry. Change the header frame, and the model changes with it.

Download

compunet-logo.3mf Multi-colour. Use this one. Contains both variants side by side — delete whichever you don't want
compunet-logo.stl Single colour, everything merged — for previewing, or a one-filament print

Printing it

Two variants are in the 3MF. Raised stands the lettering 2.5 mm proud of the plate (pictured); flush inlays the colour into the top face so the surface is one continuous plane.

Size212 × 42 mm, 15 mm thick — heavy enough to stand on its long edge
FilamentsThree: light grey, red, blue (the authentic C64 palette values)
SupportsNone. It's a flat slab — print face-up
InfillDrop it to ~10%. Nothing structural happens below the top layer
Colour changesOne, near the top. All three colours share the final layers, so the AMS purges four times, not throughout

Bambu Studio will warn that the file isn't a Bambu Lab project and load "geometry and colour data only" — that's expected and the colours still come through. The generator and full printing notes are in the repository.
