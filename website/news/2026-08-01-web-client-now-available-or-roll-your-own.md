# Web client now available... or roll your own!

We recently launched a WEB CLIENT that makes it easier than ever before to connect to Compunet
Reborn. Nothing beats using a C64 (perhaps an Amiga?) but now you can do it from the comfort of
your own web browser.

It runs in any modern browser, with nothing to install. The same code also packages into a proper
desktop app, so native Windows, Mac and Linux versions follow from the same source — Windows is
already built and won't be far behind.

All available via [https://compunet.live/](https://compunet.live/)

## Roll your own client

Alongside the web client, we've taken everything that makes Compunet what it is - the look and
feel, the frame and directory formats, how uploads, downloads, mail and Partyline work, right down
to the bytes on the wire - and codified it into a formal specification.

Nine separate clients have been built from that document alone — each by a fresh builder with no
access to the Compunet source, and each tested against the live server. Every point where the spec
turned out to be silent, ambiguous or simply wrong was logged and fixed.

So if you fancy a Compunet client for a machine we haven't thought of, everything you need is
here:

[https://github.com/tgreaves/compunet-reborn/tree/main/docs/spec](https://github.com/tgreaves/compunet-reborn/tree/main/docs/spec)
